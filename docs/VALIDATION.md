# Проверка etask 1.0.0

Дата — 9 ноября 2026 года. Рабочая ветка feat/etask-project-workflow.
Изменения подготовлены локально; этот отчёт не означает публикацию релиза.

что любая модель всегда исполнит инструкции и действительно проведёт review.
Checkpoint является явно обозначенной аттестацией агента.

## Диагностика и хосты

Doctor и status выполнены в самом every-task с реальным git и чтением GitHub
через gh. Проверены профиль v2, команды, origin, авторизация и dev.
Для существующего sandbox-owned .git использовался временный safe.directory
только для этого пути, без глобальной смены настроек.

Claude plugin validate для исходников прошёл. Предупреждение о корневом
CLAUDE.md относится к разработке исходников; этот файл не входит в архив.
Рекомендация валидатора о короткой команде установки не меняет вердикт.

Полный новый workflow с живой моделью в Codex/Claude/Gemini в этой версии
не прогонялся. Установка/обнаружение версии 0.1.0 проверялись ранее, но это
не считается доказательством поведения 1.0.0. Jira/MCP не вызывались.
GitHub Actions, реальная публикация релиза, merge и удаление веток в рамках
этой реализации не выполнялись и проверяются после отдельных разрешений.

## Зависимости и среда

Runtime плагина использует встроенные модули Node.js 22+.
Разработка и semantic-release требуют Node.js ^22.14.0 или >=24.10.0.
На машине оставлен глобальный Node.js 22.12.0; для проверки использовался
Node.js 22.23.4 в игнорируемом временном каталоге проекта.

Первоначальная semantic-release 24.2.9 заменена на 25.0.9 после npm audit.
Последний сетевой аудит: 35 moderate, 0 high, 0 critical. Предупреждения
связаны с bundled-зависимостями транзитивного npm 11.21.2; совместимый
npm audit fix их не устраняет. --force и неподтверждённые overrides не применялись.
Эти пакеты не входят в пользовательские архивы. Проект не использует
стандартный npm publish plugin; настроен собственный gh-адаптер.
Это ограничивает применимость предупреждений, но не означает нулевой риск.
Offline npm audit не считается достоверным результатом проверки уязвимостей.

В sandbox атомарное переименование временных файлов было заблокировано.
Те же тесты с штатным разрешением среды прошли; атомарная запись сохранена.
Нативные проверки хостов и тесты инструментов отражаются раздельно.

## Review и санитайз

После изменений выполнялись отдельные проходы review и санитайза.
Исправлены обнаруженные случаи: завершение github без правки защищённой
ветки, восстановление local done после переноса, изменяющий исходники тест,
повтор публикации draft, версии в release-архивах и зависимости релизного инструмента.
Финальный проход выполняется по всему diff относительно dev.
Это собственное ревью исполнителя, не независимое ревью другим агентом.

При последующем ревью PR #3 обнаружены и воспроизведены три пропущенных случая:
критерии завершённой зависимости менялись без блокировки, fenced-пример становился
задачей, а продвинувшаяся main приводила к пропуску раннего выпуска.
Регрессионные тесты сначала показали ошибки. Исправления связывают completion
с определением задачи, сохраняют позиционный разбор Markdown без fenced-примеров
и обрабатывают невыпущенные SHA по истории main через изолированные Git-снимки.
Проверены новые merge во время обработки очереди, повтор после сбоя и неизменность
исходной main при расчёте последовательных версий. Живая публикация остаётся pending.
