# Проверка ET-2: update

Версия исходников и адаптеров — 1.1.0. Она не означает опубликованный выпуск.
План согласован пользователем; реализация находится в feat/et-2-plugin-update.

## Автоматические проверки

Тесты update используют реальные временные каталоги и ZIP-архивы.
Изменяющие установку команды хостов заменены управляемыми исполнителями:
это не доказательство полноценной установки в живом хосте.

- Числовое сравнение стабильных версий, отсутствие downgrade и переустановки.
- Получение стабильного релиза, выбор архива хоста, обязательные digest и SHA.
- ZIP store/deflate, CRC, границы размеров, расхождения заголовков,
  ссылки, шифрование, опасные пути, дубли и коллизии файлов/каталогов.
- Обновление Codex/Claude/Gemini с сохранением прежней копии и документов.
- Отсутствующий, неоднозначный, отключённый или чужой project-scope плагин.
- Ошибки скачивания, контрольной суммы, штатной установки и проверки версии.
- Блокировка параллельных запусков и недопустимых каталогов хранения.
- Журнал восстановления и поддержка старого кэша с Git-метаданными.
- Диспетчеризация update без профиля проекта и упаковка всех инструментов.

## Фактические проверки окружения

На Windows с Node.js 22.23.4 выполнены чтение установленной версии Codex
через новый runner, запрос GitHub Release через gh и загрузка настоящего
архива v1.0.0. Проверены SHA-256, RELEASE.json, версия и commit
9e00c3fcf340ea39d33320a39c0a1fb1587187fd.
ZIP-проверка также прочитала все три опубликованных архива v1.0.0.

Реальная установленная версия Codex при чтении — etask 0.1.0. Она не изменялась.
Команды Codex и Claude сверены по локальному --help; формат регистрации
Codex — по фактическому JSON. Поведение переподключения Codex и команды Gemini
дополнительно сверены по исходникам официальных репозиториев через gh.
Gemini CLI на машине отсутствует. Полные прогоны обновления и восстановления
в живых профилях трёх хостов остаются pending в MANUAL_CHECKS.md.

## Review и санитайз

Отдельно проверены диспетчеризация до setup, выбор текущего хоста и scope,
сохранность предыдущего пакета, границы каталогов, команды регистрации,
обработка частичного сбоя и проверка результата CLI.
Обнаруженный старый кэш Codex с .git покрыт сначала падающим тестом:
метаданные репозитория теперь исключаются из резервной копии, не удаляясь
из исходного каталога.

Runtime остаётся на встроенных модулях Node.js; новых зависимостей нет.
Исходные файлы не превышают 500 строк и не содержат комментариев/debug-кода.
Проверка является собственным review исполнителя.
