## ET-3 — Учитывать Git ignore в снимках GitHub-проектов

- Тип — fix
- Исполнитель — kArteraa
- Состояние — testing
- Зависимости — ET-2

### Что сделать

Согласованное исправление: изменение игнорируемых генерируемых кэшей Unity
не должно отменять проверки неизменившихся исходников. GitHub-снимок включает
отслеживаемые и новые неигнорируемые файлы; local сохраняет прежнее поведение.
Глобальная установка и релиз не входят в эту рабочую ветку.

### Готово, когда

- [x] Unity Library/Temp/Logs/UserSettings, исключённые через .gitignore,
  не отменяют свидетельства и успешную CLI-проверку.
- [x] Изменение/удаление отслеживаемого кода, новых FBX/.meta, профиля,
  цели и критериев задачи отменяет актуальность проверки.
- [x] Игнорирование не скрывает отслеживаемый код и обязательные документы.
- [x] Windows-пути, ссылки и отсутствие Git проверены, local не изменён.
- [x] Выполнены отдельные review/санитайз, test/unit/integration/e2e/lint/build.
