# Цель every-task

Дать пользователю Codex, Claude Code и Gemini CLI один управляемый процесс разработки:
от цели проекта и согласованных задач до проверенного локального результата или PR.
Работа сохраняется в проекте, переносится между сессиями и устройствами и остаётся
проверяемой через тесты, code review и санитайз после каждой правки.

## Критерии результата

- Можно начать проект локально без GitHub и Jira либо явно выбрать GitHub.
- Пользователь видит цель, задачи, зависимости, четыре статуса и блокеры в Markdown.
- Агент продолжает работу по фактам и сохраняет обязательные подтверждения.
- Установка, диагностика и обновление процесса понятны без чтения исходного кода.
