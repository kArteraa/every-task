# Конфигурация

Текущий формат — [версия 2](../assets/config-v2.schema.json).
[Схема v1](../assets/config.schema.json) сохранена только для явной миграции.

| Поле | Смысл |
| --- | --- |
| project.name, goal, owner | Название, путь документа цели, явный исполнитель |
| workflow.mode | Обязательный выбор local или github |
| workflow.git | Используется ли Git; для github true |
| workflow.integrationBranch, productionBranch | Разные явные имена веток; null без Git |
| workflow.repository | owner/repo, только для github |
| paths.backlog, board | Источник задач и Markdown-доска |
| paths.queue | Очередь либо null |
| paths.decisions, manualChecks | Решения либо null и ручные проверки |
| checks.test, unit, integration, e2e | Обязательные команды и cwd |
| checks.lint, build | Команда/cwd либо согласованный skip с причиной |
| reviewers | Согласованные GitHub-логины |
| jira | Явно выключенная либо полностью настроенная интеграция |

Примеры [local](../assets/config.local.example.json) и
[github](../assets/config.github.example.json) показывают форму.
Это не настройки по умолчанию: пользователь выбирает и согласовывает значения.
Jira независима от GitHub и требует явного разрешения на MCP.

Пути относительны к проекту, используют /; cwd корня — точка.
Запрещены выход через .., абсолютные пути, symlink/junction наружу,
совпадающие документы и перезапись служебных файлов .etask.
Секреты не хранятся в профиле. Неизвестные поля — ошибка.

Команды выполняются в shell ОС. Прочитай их до запуска, особенно в чужой
ветке. Изменение команды требует согласования и новых результатов.
Для unit/integration/e2e нет автоматического skip.

## Миграция

Сохрани настройки v1. Запроси mode, цель, owner, board, ветки и команды
отсутствующих уровней тестов. Покажи полный профиль v2 и замену старого
in-review на testing в бэклоге. После согласования сохрани резервную копию
вне публикуемых файлов и сравни исходный файл перед записью.
Конфликты не перезаписывай, документы не пересоздавай из шаблонов.

Цель, задачи, решения и доска переносятся вместе с проектом.
.etask/state.json и .etask/runs/ — локальные свидетельства, исключаемые из Git.
На другом устройстве проверки запускаются заново. Состояние не хранит разрешения.
