# etask

Один процесс выполнения задач для **Codex, Claude Code и Gemini CLI**.
Агент ведёт задачу от плана до PR, показывает результаты проверок и ждёт
подтверждений перед push и мержем.

Версия 0.1.0 — первый preview. Репозиторий `kArteraa/every-task`, лицензия MIT.
Проверенные хосты и ограничения перечислены в [отчёте](docs/VALIDATION.md).

## Начать работу

Установи пакет для своего агента по [инструкции](docs/INSTALLATION.md).
В целевом проекте вызови настройку, согласуй найденные команды проверок
и пути документов, затем передай задачу.

| Агент | Настройка | Задача | Ревью |
| --- | --- | --- | --- |
| Codex | `$etask setup` | `$etask ET-1` | `$etask review ET-1` |
| Claude Code | `/etask:etask setup` | `/etask:etask ET-1` | `/etask:etask review ET-1` |
| Gemini CLI | `/etask setup` | `/etask ET-1` | `/etask review ET-1` |

Вместо ID можно передать описание задачи. Вызов без аргументов берёт
следующую доступную задачу текущего пользователя из настроенной очереди.

## Процесс

1. Прочитать задачу, проверить зависимости и подготовить рабочую ветку от dev.
2. Представить план и дождаться одобрения.
3. Реализовать, проверить, почистить код и провести ревью.
4. Показать итоговый коммит и получить разрешение на push и PR в dev.
5. Проверить PR и получить отдельное разрешение на мерж.

main — production, dev — интеграция. Правила веток и коммитов описаны
в [общем Git-процессе](skills/etask/references/git.md).
Подтверждения привязаны к показанной версии изменений.

## Настройки

Конфигурация проекта находится в `.etask/config.json`.
Setup предлагает пути бэклога, очереди, решений и ручных проверок,
команды test/lint/build, ревьюеров и настройки Jira.
Профиль проверяется по [JSON Schema](skills/etask/assets/config.schema.json).
Все поля описаны в [справочнике](skills/etask/references/configuration.md).

Jira выключена по умолчанию. Для включения нужны профиль проекта,
авторизованный Atlassian MCP и явное разрешение пользователя на его
использование. GitHub обрабатывается через gh, Git-операции через git.

## Разработка из исходников

Нужны Node.js 22 и npm. Установленный плагин выполняет инструкции
инструментами выбранного агента.

```sh
npm ci --ignore-scripts
npm test
npm run lint
npm run build
```

Сборка создаёт `dist/etask-0.1.0-codex.zip`, `dist/etask-0.1.0-claude.zip`
и `dist/etask-0.1.0-gemini.zip`. Каждый архив содержит общий навык,
справочники, шаблоны и метаданные соответствующего хоста.

Проверки JSON, ссылок и упаковки дополняются
[поведенческими сценариями](evals/scenarios.md).
Исполнитель фиксирует отдельно результаты автоматических проверок,
наблюдаемые действия агента и совместимость установленного хоста.
