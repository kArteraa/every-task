# Зависимости инструментов разработки

| Пакет | Версия | Лицензия | Назначение |
| --- | --- | --- | --- |
| ajv | 8.20.0 | MIT | Проверка JSON Schema конфигурации |
| fflate | 0.8.3 | MIT | Воспроизводимые ZIP-архивы |
| semantic-release | 25.0.9 | MIT | Расчёт версий, Git-теги и жизненный цикл релиза |
| smol-toml | 1.9.1 | MIT | Проверка команды Gemini CLI |
| yaml | 2.9.1 | ISC | Frontmatter навыка и метаданные Codex |

Транзитивные версии зафиксированы в package-lock.json. Их тексты лицензий
поставляются вместе с npm-пакетами. Архивы плагина содержат инструкции и
метаданные и runtime на встроенных модулях Node.js; npm-зависимости используются
только при разработке, проверке, сборке и выпуске.

Процесс основан на предоставленных владельцем инструкциях AlphaImpact.
